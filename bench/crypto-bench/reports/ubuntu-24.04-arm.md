### What this says we should ship

* **ChaCha20: ship the ladder on this platform.**  
  The gate above fails the job on a single length below 1.00x, and this run produced none, on any of the four runners in the matrix. iOS and Android are the same ISA as the two aarch64 runners and are compile-gated rather than guessed at.
* **SHA-1: ship it here.**  
  The portable core's worst length here is 1.71x. ZeroNet's only SHA-1 is the 55-byte WebSocket handshake, so this is the number that matters.
* **SHA-256: bump the pin.**  
  The hardware backend in `sha2` 0.11 measures 5.83x at its worst here against the 0.10 pin ZeroNet resolves today; the portable core measures 1.80x. Where the CPU already had those instructions it is 1.00x, so it is a strict improvement on every platform. But note what the same column reads on the other runners: this is a dependency bump, not a new core, and the win is all aarch64 -- SHA-NI was already there on x86_64 and 0.11's runtime dispatch costs a few percent it never gives back.
